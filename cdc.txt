1. Présentation de SMART2D Services
SMART2D Services est un cabinet de conseil technologique basé à Lomé, spécialisé dans les environnements critiques, avec une expertise forte autour des technologies Oracle, des bases de données, des systèmes Linux/Unix, du Cloud OCI, de la sécurité, de la supervision et de l'automatisation.
L'entreprise accompagne notamment les banques, institutions financières, télécoms et organisations exigeantes dans l'administration, l'audit, la sécurisation, l'optimisation, la migration, la digitalisation et le maintien en condition opérationnelle de leurs plateformes informatiques.

Accents secondaires	Bleu nuit pour infrastructure/cloud, vert discret pour sécurité/disponibilité
Crème	#F8F6F4 — background principal du site

Logo footer	Logo complet SMART 2D SERVICES
Police principale	Inter (Google Fonts, sans-serif)
Police secondaire	Geist Mono (monospace)

Exigences visuelles
•	Éviter un site trop blanc, vide ou figé.
•	Créer une harmonie entre sections claires, sombres et légèrement teintées.
•	Prévoir des animations sobres : apparition au scroll, transitions boutons, cartes au survol, compteurs animés. Technologie : Framer Motion (bibliothèque React).
•	Garantir une excellente lisibilité : contraste fort, police moderne, tailles confortables, paragraphes courts.
•	Concevoir d'abord pour mobile puis enrichir l'expérience desktop et grand écran.
•	Respecter `prefers-reduced-motion` pour limiter les animations si l'utilisateur le demande.
Breakpoints de référence
Format	Largeur indicative	Exigence
Mobile	< 768 px	Navigation compacte, textes lisibles sans zoom, boutons faciles à toucher
Tablette	768 à 1279 px	Grilles adaptées, sections aérées, images bien recadrées
Desktop	1280 à 1599 px	Composition riche, largeur de lecture contrôlée
Grand écran	>= 1600 px	Mise en page valorisée, pas de grandes zones vides, contenu maîtrisé

10. Spécifications techniques
Architecture technique cible
Stack	Next.js 16 / React 19 (App Router)
Langage	TypeScript 5.7
Style	Tailwind CSS v4 (via @tailwindcss/postcss)
Animations	Framer Motion
Composants UI	shadcn/ui (basé sur Radix UI)
Icônes	lucide-react
Analytics	Vercel Analytics
Contenus	Intégrés dans les composants React (pas de fichier JSON centralisé)
Hébergement	cPanel chez prestataire
Hypothèse actuelle	cPanel supporte Node.js
Plan de secours	Export statique Next.js si Node.js non disponible

Pré-requis cPanel à vérifier avant mise en production
•	Présence d'une option de type Setup Node.js App, Application Manager ou équivalent.
•	Version Node.js disponible, idéalement Node.js 20 ou 22.
•	Disponibilité de npm.
•	Possibilité de définir des variables d'environnement.
•	Configuration HTTPS/SSL et redirection HTTP vers HTTPS.
•	Choix de gestion du formulaire : Node.js, PHP cPanel ou service externe.
Hébergement des assets
•	Les logos SMART2D sont hébergés sur Vercel Blob Storage (URLs externes). À migrer en local dans /public avant déploiement cPanel.
•	Les images hero (7 fichiers, 1 à 1.5 Mo chacune) sont en /public/images/hero/. L'optimisation d'images Next.js est désactivée (images.unoptimized: true). Compresser manuellement avant mise en production.
