4.	Le Scan des chèques
 

L’application propose le scan des chèques directement dans l’interface Web.
Selon votre mode de traitement, vous pouvez accéder au menu de scan qui vous convient :

Menu « Chèques\Scan des Chèques » : Pour scanner les chèques avec ou sans les bordereaux de remise.

 


Zone 1 : Menu “Scan des Chèques”
Cette zone se trouve dans le menu latéral gauche de l’application SmartACCESS.
Elle permet d’accéder à la fonctionnalité de scan des chèques.
•	Pour y accéder, l’utilisateur clique sur Scan des Chèques.

Zone 2 : Sélection de la machine de scan
Cette zone contient un menu déroulant intitulé Machine de Scan.
Elle permet de sélectionner la machine (scanner) qui sera utilisée pour la numérisation.
•	Chaque utilisateur peut être rattaché à une machine spécifique, par exemple :
MACHINE02-MACHINE02

Zone 3 : Panneau de commande du scanner
Cette zone regroupe les différents boutons de contrôle du scanner.
C’est ici que l’utilisateur effectue les actions nécessaires au déroulement complet du scan.
Voici le déroulement logique des actions :
1.	Initialiser le Scanner
o	Permet d’établir la connexion entre l’application et le périphérique (scanner).
o	Cette étape est obligatoire avant toute autre action.
2.	Activer les Options
o	Une fois le scanner initialisé, on active les paramètres nécessaires au fonctionnement
3.	Démarrer le Scan
o	Lance le processus de numérisation des chèques.
o	Les images et données (montant, numéro, etc.) sont récupérées automatiquement.
4.	Arrêter le Scan
o	Permet de mettre fin à la session de numérisation.
o	À effectuer une fois que tous les chèques ont été scannés.

 6.	Création des effets
 

Écran : Création des Effets
Cet écran permet à l’utilisateur de créer un effet (lettre de change, billet à ordre, etc.) en renseignant les informations du tireur, du bénéficiaire, et les caractéristiques de l’effet.

 


Zone 1 : Menu “Création Effets”
Située dans le menu latéral gauche, cette zone permet d’accéder à la fonctionnalité de création d’un nouvel effet.
•	Pour y accéder, cliquez sur Création Effets.
•	Ce menu regroupe toutes les opérations liées à la gestion des effets (création, liste, suivi)..

Zone 2 : Informations sur l’Effet
Cette zone contient tous les champs nécessaires à la définition de l’effet.
Les champs principaux sont :
•	Type d’Effet : permet de choisir la nature de l’effet
(ex. 045 – Billet à ordre nouvelle norme).
•	Date d’échéance : date à laquelle l’effet devra être payé.
•	Date de création : date de saisie de l’effet dans le système.
•	Numéro de l’Effet : identifiant unique de l’effet.
•	Montant : valeur monétaire de l’effet.
Des cases à cocher complètent les informations :
•	✅ Escompté ? → indique si l’effet est escompté.
•	✅ Avalié ? → indique si l’effet est avalisé par une tierce personne.
•	✅ Protestable ? → permet de signaler si l’effet peut faire l’objet d’un protêt.
•	✅ Frais au Tiré ? → précise si les frais sont à la charge du tiré.

Zone 3 : Informations sur le Bénéficiaire
Cette section regroupe les coordonnées du bénéficiaire de l’effet.
Les champs à renseigner sont :
•	Compte Bénéficiaire : numéro de compte du bénéficiaire.
o	Si le compte remettant entré à l’écran, existe les informations seront récupérées et affichées à l’écran ; sinon, un message d’erreur informera l’utilisateur. 

•	Banque Bénéficiaire : seront récupérées automatiquement.
•	RIB Bénéficiaire : seront récupérées automatiquement.
•	Nom Bénéficiaire : seront récupérées automatiquement.

Zone 4 : Informations sur le Tiré / Souscripteur
Cette partie contient les informations du tireur ou souscripteur (celui qui émet ou s’engage sur l’effet).
Les champs incluent :
•	Nom du Tiré / Souscripteur : à renseigner
•	RIB du Tiré : à renseigner
•	Banque, Agence, Compte, RIB (sélectionnés à partir des listes déroulantes) à renseigner.

Zone 5 : Bouton de création
Une fois toutes les informations saisies, l’utilisateur doit cliquer sur le bouton Créer pour enregistrer l’effet.
•	Si les champs obligatoires sont bien remplis, l’effet est enregistré avec succès.
•	En cas d’erreur ou de champ manquant, un message d’alerte s’affiche pour correction.

7.	Création des virements
 


Écran : Création de Virements
Cet écran permet de créer un virement client entre un donneur d’ordre (celui qui envoie les fonds) et un bénéficiaire (celui qui reçoit les fonds).

 


Zone 1 : Menu “Création Virements”
Cette zone se situe dans le menu latéral gauche de l’application SmartACCESS.
Elle permet d’accéder à la page de création d’un nouveau virement.
•	Pour y accéder, cliquez sur Création Virements.



Zone 2 : Informations du Donneur d’Ordre
Cette section contient les informations de la personne ou de l’entreprise à l’origine du virement.
Les champs à renseigner sont :
•	Type de Virement : choisir le type dans la liste déroulante
(exemple : 015 – Virement Standard de clientèle nouvelle norme).
•	Banque : code de la banque du donneur d’ordre (ex. TG160).
•	Numéro de Compte : numéro de compte du client qui effectue le virement (champ obligatoire marqué d’un *).


Zone 3 : Informations du Bénéficiaire
Cette zone permet de saisir les informations concernant le destinataire du virement.
Les champs sont :
•	Montant* : somme à transférer.
•	Nom Bénéficiaire* : nom du bénéficiaire du virement.
•	Libellé : description ou motif du virement (exemple : VIREMENT CLTE).

Zone 4 : Coordonnées bancaires du bénéficiaire (RIB Bénéficiaire)
Cette sous-section permet de préciser les détails bancaires du bénéficiaire.
Les champs à remplir sont :
•	Banque : sélectionner la banque du bénéficiaire.
•	Agence : choisir l’agence où le compte est domicilié.
•	Compte Bénéficiaire* : numéro de compte du bénéficiaire.
•	RIB* : identifiant bancaire complet (Relevé d’Identité Bancaire).


Zone 5 : Bouton “Créer”
Après avoir renseigné toutes les informations obligatoires :
1.	Cliquez sur le bouton “Créer” pour valider la saisie.
2.	Le virement s’ajoute à la liste des virements en attente de traitement.
3.	Si un champ obligatoire est manquant, un message d’erreur s’affiche pour correction.

10.	Les chèques, effets et virements prêt pour ICOM1 (Mise en erreur )
 

Après la saisie des chèques, ceux-ci deviennent prêts pour ICOM1, c’est-à-dire l’envoi vers la BCEAO (Banque Centrale).
Avant cet envoi, les utilisateurs disposent d’un écran de contrôle permettant de visualiser l’ensemble des chèques à transmettre.
Cet écran offre une dernière étape de vérification avant que les fichiers soient effectivement transmis à la BCEAO.



 

Étapes à suivre pour mettre un chèque en erreur
1.	Localisez le chèque concerné dans la liste affichée à l’écran.
2.	Cliquez sur le chèque pour le sélectionner.
3.	Cliquez sur le bouton rouge “Mise en Erreur” situé en haut de l’écran.
4.	Le chèque passera automatiquement à l’état “22 - Mise en erreur”, ce qui signifie qu’il ne sera pas pris en compte dans le lot ICOM1.
NB : Vous pouvez effectuer le même processus pour les effets et les virements, dans leurs menus respectifs.
Les écrans et les boutons fonctionnent de la même manière pour ces opérations.

13.	Vérification des chèques par les opérationnels et gestionnaires
 
Après la réception du fichier OUTGO, les opérationnels (OPS) et les gestionnaires (GES) procèdent à la vérification des chèques retours à travers les écrans dédiés :
•	Vérification des Chèques (OPS)
•	Vérification des Chèques (GES)
Ces deux écrans permettent de contrôler les images et les informations des chèques retournés avant leur validation ou leur rejet définitif.

 

1. Vérification par les OPS (Première étape) (chèques état = 150)
Les OPS effectuent la première vérification des chèques :
•	Ils vérifient la signature, le montant, la date, et les informations du compte.
•	Si une anomalie est constatée, ils peuvent rejeter le chèque en sélectionnant d’abord un motif de rejet dans la liste prévue 
•	 
Impact : les chèques passe à l’état 250 ;

•	Si tout est conforme, ils valident le chèque.
 
	Chèques passe à l’état = 180
Si le chèque nécessite une vérification ultérieure 
•	Cliquer sur le bouton « En attente ».
•	Le chèque est temporairement mis de côté pour être revu plus tard.

 


Les chèques validés par les OPS passent alors à l’étape suivante pour être contrôlés par les GES.

3.Vérification par les GES (Seconde étape)
Une fois la première vérification terminée :
•	Les GES prennent la main sur les chèques validés par les OPS.
•	Ils effectuent une seconde vérification pour confirmer la conformité du chèque.
•	Comme les OPS, ils peuvent à leur tour :
o	✅ Valider le chèque s’il est conforme.
o	❌ Rejeter le chèque en précisant le motif de rejet approprié.


NB : Dans l’écran de vérification, l’utilisateur dispose de la possibilité de mettre un chèque en attente afin de procéder à des vérifications ou validations ultérieures.
Nombre maximum d’attentes autorisées :
Un même chèque peut être mis en attente jusqu’à 4 fois consécutives.
À la 5ᵉ tentative, il est obligatoire de statuer définitivement sur le sort du chèque (acceptation ou rejet) avant de passer au chèque suivant.

 
14.	Les chèques, effets et virements prêt pour ICOM2 (Mise à jour)
 
Après la phase de vérification des chèques par les OPS (opérationnels) et les GES (gestionnaires), certains chèques peuvent être refusés pour diverses raisons (signature non conforme, montant erroné, informations manquantes, etc.).
Une fois refusés, ces chèques passent automatiquement à l’état “Prêt pour ICOM2”, correspondant à l’envoi des rejets à la BCEAO.

 
 
Étapes à suivre pour mettre un chèque à jour
1.	Localisez le chèque concerné dans la liste affichée à l’écran.
2.	Cliquez sur le chèque pour le sélectionner.
3.	Cliquez sur le bouton rouge “Mise à jour” situé en haut de l’écran.
4.	Le chèque passera automatiquement à l’état “180 - Mise à jour ”, ce qui signifie qu’il ne sera pas pris en compte dans le lot ICOM2.

NB : Vous pouvez effectuer le même processus pour les effets et les virements, dans leurs menus respectifs.
Les écrans et les boutons fonctionnent de la même manière pour ces opérations.

15.	Génération des fichiers CRO / EXR
 

1. Fichier CRO
Le fichier CRO est généré automatiquement après la réception du fichier OUTGO.
Il contient les informations liées aux chèques retours reçus de la BCEAO.
Ce fichier est déposé automatiquement dans le répertoire suivant :
C:/smartaccess/interfaces/sortie/retour/
________________________________________
2. Fichier EXR
Le fichier EXR est quant à lui généré manuellement par les OPS après la phase de vérification des chèques retours.
Il contient uniquement les chèques validés, c’est-à-dire ceux ayant satisfait aux critères suivants :
•	Signature conforme,
•	Chèque régulier,
•	Provision disponible,
•	État = 180.
Le fichier EXR est également disponible dans le répertoire suivant :
C:/smartaccess/interfaces/sortie/retour/
